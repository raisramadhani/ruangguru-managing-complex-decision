Simulasi Perbandingan Arsitektur Logika

Lihat perbedaan kompleksitas ketika semua kriteria dicampur dalam satu tumpukan besar (Kolom Kiri) dibandingkan dengan pengelompokan berbasis fungsi kecil yang modular (Kolom Kanan).

Arsitektur 1: Monolitik

Tanpa Pemecahan Fungsi

Semua kriteria dievaluasi dalam satu blok kondisional yang sama. Alur logika terlihat padat dan lebih sulit dipetakan.

Kandidat Masuk
Evaluasi List Kriteria (1-by-1)
1. usia >= 16
2. usia <= 35
3. edu == 'S1' and gpa >= 3.0
4. or (edu == 'SMA' and gpa >= 7.5)
5. exp >= 1 and laptop == 'high'
6. or (exp >= 1 or laptop == 'medium')
⏳

Menunggu Hasil

Evaluasi monolitik sedang berjalan.

Arsitektur 2: Modular

Terbagi Menjadi Fungsi Kecil

Kriteria dikelompokkan sesuai fungsinya. Klik pada kotak fungsi untuk melihat detail implementasi kode di dalamnya.

Kandidat Masuk

Fungsi 1: Usia

Menghitung...

▼ 
def check_age(age):
    if age < 16:
        return False, "Too young"
    elif age > 35:
        return False, "Too old"
    return True, "Age OK"

Fungsi 2: Akademik

Menghitung...

▼ 
def check_acad(edu, gpa):
    if edu == "SMA" and gpa >= 7.5:
        return True, "Valid"
    elif edu == "S1" and gpa >= 3.0:
        return True, "Valid"
    return False, "Invalid"

Fungsi 3: Teknis

def check_tech(exp, laptop):
    if exp >= 1 and laptop == "high":
        return True, "Advanced"
    elif exp >= 1 or laptop == "medium":
        return True, "Basic"
    return False, "Not Ready"
